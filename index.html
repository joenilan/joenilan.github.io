One signed repository for all of these apps: install once, then your system's normal updates (dnf upgrade, apt upgrade, pacman -Syu, Discover, GNOME Software) keep them current. Available now: LinX. Jawjack and Haiwire are coming.

Signing key fingerprint: E72D 6EE9 C417 012E CE28 0124 E14B 8780 7621 D25D

Fedora

sudo dnf config-manager addrepo --from-repofile=https://joenilan.github.io/packages/joenilan-apps.repo
sudo dnf install linx

Debian 13 / Ubuntu

sudo curl -fsSLo /usr/share/keyrings/joenilan-apps-archive-keyring.gpg https://joenilan.github.io/packages/joenilan-apps.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/joenilan-apps.sources https://joenilan.github.io/packages/joenilan-apps.sources
sudo apt update
sudo apt install linx

Arch Linux

curl -fsSL https://joenilan.github.io/packages/joenilan-apps.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key E72D6EE9C417012ECE280124E14B87807621D25D
curl -fsSL https://joenilan.github.io/packages/joenilan-apps.pacman.conf | sudo tee -a /etc/pacman.conf
